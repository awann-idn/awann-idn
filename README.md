### SIGAP

Proyek yang lagi gue kerjain. Sistem pelaporan titik api karhutla berbasis web untuk Sumatera Selatan, dibuat bareng tim Infinitera.

Problemnya sederhana: laporan titik api selama ini susah diverifikasi karena orang bisa kirim foto lama, koordinat ngasal, atau spam. Jadi sistemnya gue buat dengan validasi GPS vs EXIF foto, rate limiting per perangkat, dan dashboard verifikasi khusus untuk petugas BPBD sebelum titik api tayang ke peta publik.

Tech stack-nya Next.js 14, TypeScript, PostgreSQL (Neon), Upstash Redis buat rate limiting, Supabase Storage buat foto, sama Three.js buat visualisasi 3D di halaman beranda.
