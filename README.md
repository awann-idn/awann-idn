<td width="60%">

**[SIGAP — Wildfire Reporting System](https://github.com/awann-idn/sigap)**

Platform web pelaporan titik api karhutla berbasis geolokasi untuk wilayah Sumatera Selatan.

- 📍 Deteksi lokasi via **Geolocation API** + reverse geocoding
- 📷 **Kamera live** dengan validasi EXIF — cegah foto palsu
- 🔬 **Confidence scoring** dari selisih GPS vs EXIF metadata
- 🗺️ Peta sebaran publik hanya tampilkan laporan **terverifikasi**
- 🛡️ Dashboard petugas BPBD dengan **cookie HttpOnly auth**
- ⚡ Rate limiting via **Upstash Redis**
